# 《鸿毛》灰盒试玩与操作说明

本文面向第一次打开工程的试玩者，目标是完整体验一次“防御充能 → 吸色 → 强化攻击 → 红脸谱”的战斗循环。

## 开始试玩

1. 使用 Unity `6000.3.23f1` 打开项目。
2. 双击 `Assets/HongMao/Scenes/PrototypeCombat.unity`。
3. 查看 `Window > General > Console`，确认没有红色编译错误。
4. 点击顶部 Play 按钮。
5. 点击 Game 窗口，使键盘和鼠标输入进入游戏。

## 按键表

| 状态 | 操作 | 按键 |
| --- | --- | --- |
| 通用 | 左右移动 | `A` / `D` |
| 通用 | 单跳 | `Space` |
| 通用 | 闪避 | `Shift` |
| 通用 | 攻击 | 鼠标左键 |
| 通用 | 招架 | 鼠标右键 |
| 通用 | 进入吸色 | 充能满后按 `Q` |
| 吸色中 | 确认目标 | 鼠标悬停红色源并点击左键 |
| 吸色中 | 取消 | 鼠标右键、`Q` 或 `Esc` |
| 有强化攻击时 | 突进斩 | 不按上下方向，点击左键 |
| 有强化攻击时 | 上挑 | `W` + 鼠标左键 |
| 有强化攻击时 | 空中下砸 | 空中 `S` + 鼠标左键 |
| 三个红槽时 | 红脸谱 | `R` |
| 胜利／失败后 | 重新开始 | `Enter` |

地面按 `S` + 左键不会触发下砸，只会执行普通攻击，也不会消耗强化攻击机会。

## 推荐体验路线

1. 先观察敌人攻击提示。偏黄色的攻击可以招架，橙色攻击不可招架，需要闪避。
2. 用一次成功招架和一次精准闪避把充能补到 3 格。
3. 按 `Q` 进入慢动作，将鼠标移动到红色物体上并点击左键。
4. 用获得的强化机会测试突进斩。
5. 再完成两轮充能和吸色，分别测试上挑与空中下砸。
6. 先打空敌人霸体，再用上挑将其挑空并追加一次空中攻击。
7. 三个红槽集齐后按 `R`，使用红脸谱专属攻击击败敌人。
8. 另开一局主动承受伤害，确认失败后按 `Enter` 可以正常重开。

## HUD 信息

- 左上绿色条：玩家生命。
- 左上三格“充能”：招架与精准闪避获得的资源。
- 左上三格“红槽”：成功吸色后填充。
- “强化攻击：就绪”：下一次符合方向条件的攻击会使用强化招式。
- 右上红条：敌人生命。
- 右上黄条：敌人霸体；清空后短时间内可被挑空。
- 红脸谱发动后，HUD 会显示剩余持续时间。

## 当前灰盒限制

- 角色与场景均为几何占位图，不代表最终碰撞轮廓和动画节奏。
- 敌人只有一套固定循环，用于稳定验证招架和闪避。
- 当前只实现红色及红脸谱。
- 尚未针对手柄和按键重绑定制作支持。
- 目前以 Unity Editor 内演示为准，没有正式 Windows/macOS 构建。

## 常见问题

### 按键没有反应

先点击一次 Game 窗口。Unity 的输入焦点可能仍停留在 Scene、Inspector 或 Console。

### 退出 Play 后位置或生命恢复了

这是 Unity 的正常行为。Play Mode 中对场景对象的临时改变不会保存；需要调整地图或参数时，应先停止 Play，再编辑并保存。

### 场景里看不到角色或地图

确认打开的是 `Assets/HongMao/Scenes/PrototypeCombat.unity`，并在 Hierarchy 中展开 `World`。不要只依赖 Play Mode 生成对象。

### 吸色后时间仍然很慢

先停止 Play Mode 再重新进入。如果问题能稳定复现，请记录操作顺序并附上 Console 截图提交 Issue。
