# Domain docs

Before working on HongMao, read the root `CONTEXT.md` when it exists,
then read ADRs in `Docs/adr/` relevant to the change.

If those files do not exist yet, continue normally. Create or update them
only when a gameplay term or design decision has actually been settled.

Use the names defined in `CONTEXT.md` consistently in issues, code, tests,
and documentation. Flag any change that contradicts an existing ADR.
